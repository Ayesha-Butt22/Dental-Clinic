Dental Clinic Website is a frontend-only React.js project designed to demonstrate a clean, professional, and patient-friendly healthcare UI. The website follows modern UI/UX principles with a trust-focused blue color palette, responsive layout, and reusable component-based architecture. It includes pages such as Home, About, Services, Doctors, Appointment (UI demo), and Contact. All data used is dummy and intended for portfolio showcase purposes only. The project highlights strong frontend skills using React.js, Tailwind CSS, and modern design standards, and can be easily extended with backend integration in the future.
